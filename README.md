# FUKUOKA GTFS Station Navigator

アーバンデータチャレンジ2026向けに、福岡市地下鉄の公開GTFSデータから駅・出入口情報を抽出し、再利用しやすい形式に加工したデータ作品です。応募者はROOOMTECH株式会社です。

## 作品タイプ
**データ**（道路・交通）。アプリ制作は必須ではなく、加工済みデータセット・可視化が主要成果物です。付属の `駅出口ナビ.html` はデータを閲覧するための補助ツールです。

## 成果
- 元データ `stops.txt` 318件：駅レコード37件、ホーム76件、出入口205件
- 駅名36種類（「博多」はGTFS上で駅IDが2つ）
- 親駅IDによる出入口の対応付けを全205件検証、不明な親駅0件
- 再利用可能なCSVとGeoJSONを提供

## 主なファイル
| ファイル | 内容 |

| `作品説明.md` | 背景、機能、制限、審査に向けた説明 |
| `利用手順.md` | 利用方法 |

| `検証結果.json` | 作成時のデータ品質検証 |

## 利用方法
GitHubの **Code > Download ZIP** で取得し、`駅出口ナビ.html` をChromeまたはEdgeで開いてください。公開GitHub上でのHTMLプレビューは動作しません。ローカルでの閲覧はネット接続不要です。

## 制限
現在地からの実際の徒歩経路、最新運行時刻、運休・遅延、車椅子利用可否の現況は検証・提供していません。GTFS登録座標を表示するデータ作品です。
